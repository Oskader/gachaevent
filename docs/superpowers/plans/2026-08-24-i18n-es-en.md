# Plan de implementación: la app en español, con selector ES/EN

> **Para agentes ejecutores:** SUB-SKILL OBLIGATORIA: usa `superpowers:subagent-driven-development` (recomendada) o `superpowers:executing-plans` para implementar tarea a tarea. Los pasos usan casillas (`- [ ]`) para seguimiento.

**Goal:** Que todo lo traducible de GachaEvent esté en el idioma elegido, con un selector ES/EN real, sin traducir nombres propios.

**Architecture:** Las descripciones se traducen **al scrapear** y se guardan en dos columnas (`description_en`, `description_es`), prefiriendo el español oficial del tablón de HoYoverse cuando existe. La interfaz se traduce con diccionarios tipados y un idioma que viaja en una **cookie** leída por los Server Components — sin segmento `[locale]` en las URLs.

**Tech Stack:** Next.js 16 (App Router, React 19) · Supabase Postgres · `groq-sdk` (`llama-3.3-70b-versatile`) · TypeScript.

**Spec:** `docs/superpowers/specs/2026-08-24-i18n-es-en-design.md` — léela antes de empezar. Este plan argumenta desde ella.

## Global Constraints

Copiadas literalmente del `CLAUDE.md` del proyecto y de la spec. **Se aplican a todas las tareas.**

- **NO HAY TEST RUNNER Y NO SE DEBE AÑADIR UNO.** El `CLAUDE.md` dice: *"There is no test runner and no test files... Verify changes by running `npm run dev` and exercising the page, plus `npm run build` for type errors — the build **is** the typecheck."* No instales vitest, jest ni nada parecido. Cada tarea termina con las puertas reales del proyecto, definidas abajo.
- **Todos los comandos se ejecutan desde `gachadash/`**, que es donde vive la app y el repo git.
- **`--webpack` es obligatorio en `dev` y en `build`.** No "limpies" esos scripts: `@serwist/next` inyecta configuración de webpack y Next 16 falla en duro con Turbopack.
- **Next.js 16 + React 19:** `cookies()` de `next/headers` es **asíncrono**; los `params` de ruta son una `Promise`. Leer `Date.now()` durante el render es un error de pureza que rompe el lint.
- **Nunca filtrar por título en PostgREST** (`in` / `not.in`): hay títulos con comillas dobles que no casan y fallan en silencio.
- **El color saturado solo significa urgencia.** No introducir color de marca ni `backdrop-blur` en la pantalla nueva.
- **Copia en español neutro**, sin voseo ni "vosotros".
- **No commitear ni desplegar sin que Oscar lo pida.** Los pasos de commit están escritos, pero pregunta antes de ejecutarlos.
- **Los nombres propios no se traducen**: títulos de eventos, `games.name`, y nombres de personajes, objetos y modos de juego dentro de las descripciones.

- [ ] **Paso 1: Escribir el módulo**

```ts
import Groq from 'groq-sdk'

/**
 * Traducción EN→ES de las descripciones de evento.
 *
 * El pipeline dejó de usar LLM a propósito para EXTRAER —parsear prosa
 * destruía la estructura que la fuente ya traía—, pero traducir es otro
 * trabajo: la frase ya viene limpia y verificada, y lo único que se le pide
 * al modelo es cambiarla de idioma sin tocar los nombres propios.
 *
 * Nunca lanza: un fallo deja ese evento sin traducir y la interfaz cae al
 * inglés, igual que un evento sin descripción cae a nada.
 */

const MODEL = 'llama-3.3-70b-versatile'
const CONCURRENCY = 5
const TIMEOUT_MS = 15_000

/**
 * Lo que más importa del prompt es la regla de los nombres propios: sin ella
 * el modelo traduce "Fate Gift" como "Regalo del Destino", que es justo lo
 * que no queremos.
 */
const SYSTEM = [
  'Traduces descripciones de eventos de videojuegos gacha del inglés al español neutro.',
  'REGLAS ESTRICTAS:',
  '1. NO traduzcas nombres propios: nombres de eventos, personajes, objetos,',
  '   monedas del juego, modos de juego ni títulos de juegos. Déjalos en inglés tal cual.',
  '2. NO traduzcas nada que vaya entre comillas.',
  '3. Español neutro: sin "vosotros" ni voseo.',
  '4. Mantén el mismo registro y una longitud parecida.',
  '5. Devuelve SOLO la traducción. Sin preámbulo, sin comillas alrededor, sin notas.',
].join('\n')

export interface TranslationTarget {
  key: string
  textEn: string
}

function getClient(): Groq | null {
  const apiKey = process.env.GROQ_API_KEY
  if (!apiKey) {
    console.warn('[translate] falta GROQ_API_KEY; se deja todo sin traducir')
    return null
  }
  return new Groq({ apiKey })
}

async function translateOne(client: Groq, textEn: string): Promise<string | null> {
  try {
    const res = await client.chat.completions.create(
      {
        model: MODEL,
        temperature: 0.2,
        max_tokens: 400,
        messages: [
          { role: 'system', content: SYSTEM },
          { role: 'user', content: textEn },
        ],
      },
      { signal: AbortSignal.timeout(TIMEOUT_MS) }
    )

    const out = res.choices[0]?.message?.content?.trim()
    if (!out) return null

    // Un modelo que devuelve mucho más de lo que se le dio casi siempre ha
    // añadido notas o se ha puesto a explicar. Mejor nada que basura.
    if (out.length > textEn.length * 2.5) return null

    // A veces envuelve la respuesta en comillas pese a pedirle que no.
    const unwrapped = out.match(/^"(.+)"$/s)
    return (unwrapped ? unwrapped[1] : out).trim() || null
  } catch (err) {
    console.warn(`[translate] fallo traduciendo: ${err}`)
    return null
  }
}

/**
 * Traduce en lotes. La clave del mapa devuelto es la `key` de cada objetivo;
 * los que fallen simplemente no aparecen.
 */
export async function translateToSpanish(
  items: TranslationTarget[]
): Promise<Map<string, string>> {
  const out = new Map<string, string>()
  if (items.length === 0) return out

  const client = getClient()
  if (!client) return out

  for (let i = 0; i < items.length; i += CONCURRENCY) {
    const batch = items.slice(i, i + CONCURRENCY)
    await Promise.all(
      batch.map(async (item) => {
        const es = await translateOne(client, item.textEn)
        if (es) out.set(item.key, es)
      })
    )
  }

  return out
}
```

```ts
/** Primera viñeta con sustancia bajo "Event Details" / "Detalles del evento". */
function descriptionFrom(text: string, lang: 'en' | 'es' = 'en'): string | null {
  const anchor =
    lang === 'es' ? /Detalles del evento\s*\n([\s\S]{0,600})/i : /Event Details?\s*\n([\s\S]{0,600})/i
  const section = text.match(anchor)
  if (!section) return null

  const line = section[1]
    .split('\n')
    .map((s) => s.replace(/^[•·\-\s]+/, '').trim())
    .find((s) => s.length > 40)

  if (!line) return null
  if (line.length <= 280) return line

  const cut = line.slice(0, 280)
  const lastStop = Math.max(cut.lastIndexOf('. '), cut.lastIndexOf('; '))
  return lastStop > 80 ? cut.slice(0, lastStop + 1) : `${cut.trimEnd()}…`
}
```

```ts
import { cookies } from 'next/headers'
import { es, type Dictionary } from './es'
import { en } from './en'

export type Locale = 'es' | 'en'

/**
 * `httpOnly: false` a propósito: `src/app/error.tsx` es un componente de
 * cliente que Next renderiza solo con `error` y `reset`, sin padre servidor
 * que le pase el diccionario, así que necesita leerla desde el navegador.
 */
export const LOCALE_COOKIE = 'ge_lang'
export const DEFAULT_LOCALE: Locale = 'es'

const DICTIONARIES: Record<Locale, Dictionary> = { es, en }

export function getDictionary(locale: Locale): Dictionary {
  return DICTIONARIES[locale] ?? DICTIONARIES[DEFAULT_LOCALE]
}

/** `cookies()` es asíncrono en Next 16. */
export async function getLocale(): Promise<Locale> {
  const store = await cookies()
  const value = store.get(LOCALE_COOKIE)?.value
  return value === 'en' || value === 'es' ? value : DEFAULT_LOCALE
}

export async function getI18n(): Promise<{ locale: Locale; t: Dictionary }> {
  const locale = await getLocale()
  return { locale, t: getDictionary(locale) }
}

/**
 * Descripción del evento en el idioma pedido, cayendo al otro si falta.
 * Nunca se deja una tarjeta sin texto por no tener traducción todavía.
 */
export function pickDescription(
  row: { description_es: string | null; description_en: string | null },
  locale: Locale
): string | null {
  return locale === 'es'
    ? row.description_es ?? row.description_en
    : row.description_en ?? row.description_es
}

export type { Dictionary }
```
